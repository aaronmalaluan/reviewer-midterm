What is Tableau?

Tableau is a business intelligence and data visualization tool. It lets users connect to different data sources, analyze information, create interactive visualizations, and communicate insights.

Step 1: Connect

Connect Tableau to a data source such as Excel, CSV, or a database. Example: to analyze a store's sales performance, load its sales records first.

  1. Open Tableau Public or Tableau Desktop.
  2. Locate the Connect panel.
  3. Choose Microsoft Excel or Text File, depending on your dataset.
  4. Select the dataset from your computer.
  5. Wait for the data source page to load.
  6. Confirm the required table or sheet is included.

Step 2: Inspect

Check the dataset for missing values, duplicates, and incorrect data types. Example: if Sales is read as text instead of numbers, correct it.

  1. Open the Data Source page.
  2. Review field names and the data preview.
  3. Examine the data type icons.
  4. Change incorrect data types when necessary.
  5. Identify null values or unexpected entries.
  6. Check relationships or joins when multiple tables are used.
  7. Resolve major data-quality issues before proceeding.

Step 3: Build

Create charts by dragging dimensions and measures into Rows and Columns. Example: a bar chart comparing product sales to find the highest revenue.

Groups

A Group combines multiple data members into a single category, which organizes data and makes visuals easier to read.

Create a brand group:

  1. Right-click Product Name in the Data pane.
  2. Select Create Group.
  3. Select all products of the same brand, such as Xerox.
  4. Click Group and rename it XEROX.
  5. Repeat for other brands.
  6. Rename the new group field BRANDS.
  7. Drag BRANDS and Product Name into Rows.

Sets

A Set defines a subset of data based on selected members or conditions. Tableau classifies members as In or Out.

Create a Top 5 Set:

  1. Right-click Sub-Category in the Data pane.
  2. Select Create Set.
  3. Open the Top tab.
  4. Choose By Field, then Top 5 by SUM(Sales).
  5. Click OK.
  6. Drag the Set to Color on the Marks card to separate In and Out.
  7. Drag the same Set to Label to show In/Out above the bars.
Group = combine members into one category. Set = In/Out subset based on a condition.

Step 4: Style

Improve appearance and readability.

A. Colors
Highlight important information and distinguish categories. Example: green for branches that hit sales targets, red for those that did not. Marks, then Color.
B. Labels
Show exact values on the chart, such as ₱71,500. Marks, then Label, then Show Mark Labels.
C. Filters
Show only what you want to analyze without changing the dataset. Example: CALABARZON region only. Drag the field to the Filters shelf.
D. Tooltips
Extra information on hover, such as total sales, profit, and quantity sold. Marks, then Tooltip.

Step 5: Dashboard

Combine multiple charts into one interactive view, such as total sales, monthly trends, and best-selling products.

  1. Create the visualizations in separate worksheets.
  2. Click the New Dashboard icon.
  3. Select an appropriate dashboard size.
  4. Drag worksheets into the dashboard.
  5. Arrange with horizontal or vertical containers.
  6. Add text, legends, and filters as necessary.
  7. Configure dashboard filter actions so a selection in one chart affects the others.
  8. Test that it is readable and interactive.

Step 6: Share

Present, export, or publish. Example: publish the dashboard on Tableau Public or export it as a PDF to present to management.

Data cleaning in Google Colab

Data cleaning identifies and corrects errors, inconsistencies, duplicate records, and missing values. Inaccurate or incomplete data leads to misleading analysis and poor decisions.

Sample exam question: Write Python code that shows a table of missing values per column. Answer: df.isnull().sum()

Mean vs. mode

Use mean for numerical data (Amount). Use mode for categorical data (Payment_Method: Cash, Credit Card, E-Wallet), because you cannot compute a mean or median of text.

Common mistake: fillna(df['Payment_Method'].mean()) fails on text. Use .mode()[0].
